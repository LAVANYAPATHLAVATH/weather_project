# 🌦️ Live Weather Notifier using Python

**Description:**  
This Python project fetches real-time weather information for any city using the OpenWeatherMap API.  
It supports **voice input** and **GUI display** using Tkinter, and gives **outfit suggestions** based on the weather conditions.

---

## **Features**
- Voice input for city name (using `speech_recognition`)
- Type input option available
- GUI display using Tkinter
- Shows:
  - Temperature
  - Humidity
  - Wind speed
  - Weather condition
- Outfit suggestion based on temperature, humidity, and weather
